# MySQL-Backup-Another
mysql 数据库自动备份到另外一台服务器（linux）及清理。

要实现 MySQL 数据库自动备份到另一台 Linux 服务器并定期清理，推荐使用 **`mysqldump` + `gzip` + `scp/rsync`** 的组合方案，并通过 **`cron`** 定时执行。这套方案完全基于 Linux 原生工具，无需安装额外软件，稳定且可控。
### 整体工作流程

1. **本地导出**：在数据库服务器上使用 `mysqldump` 导出数据，并直接通过 `gzip` 压缩，节省空间。
2. **远程传输**：通过 `scp`（或 `rsync`）将压缩后的备份文件安全地复制到备份服务器的指定目录。
3. **本地与远程清理**：设置保留天数，自动删除本地和远程服务器上过期的备份文件，防止磁盘写满。

## rsync方式
